# MB Expert LLC

Client project scaffold for the MB Expert LLC website.

## What this project contains

- `frontend/` - Next.js frontend for the public site
- `sanity/` - Sanity Studio schemas and content model

## What the site is for

- lead generation
- service inquiries
- trust and credibility
- a full services catalog with category pages

## Recommended content model

- `siteSettings` - brand, contact, logo, socials, CTA links
- `homePage` - hero, about, featured services, process, contact CTA
- `servicesPage` - grouped service catalog with card-level descriptions

## Working rules

- client edits copy and images in Sanity Studio
- frontend only renders approved fields
- keep schemas simple and hard to break
- keep the public site and the studio in separate responsibility zones
